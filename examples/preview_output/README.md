# 결과 파일 미리보기

이 폴더는 변환 후 파일의 **텍스트 구조만 GitHub에서 미리 보는 예시**입니다.

파일명은 기존 평면 출력을 보여 주는 최소 예시입니다. 실제 새 작업에서 `--layout`을 사용하면 `vertical_9x16/`·`horizontal_16x9/` 폴더와 방향 접미사가 붙은 파일명이 생성됩니다.

- [quick_start_with_titles.fcpxml](quick_start_with_titles.fcpxml): 화면 자막이 일반 Title로 들어간 추천 결과
- [quick_start_clean.fcpxml](quick_start_clean.fcpxml): 자막 없는 결과
- [quick_start.srt](quick_start.srt): 플랫폼 업로드용 자막

이 파일들은 예시 미디어와 사진 캐시를 포함하지 않으므로 Final Cut Pro 가져오기용이 아닙니다. 실제 작업에서는 Colab 또는 Mac 실행으로 받은 `Generated/` 폴더를 통째로 사용하세요.
