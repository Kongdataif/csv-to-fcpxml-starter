# 예제 고르기

처음이라면 **[quick_start/timeline.csv](quick_start/timeline.csv)**만 보세요. GitHub가 CSV를 표로 보여 주므로 열과 예시 값을 바로 확인할 수 있습니다.

| 예제 | 누구에게 필요한가요? | 핵심 |
|---|---|---|
| [quick_start](quick_start/README.md) | 처음 실행하는 사용자 | 기본 6열, 사진·영상 혼합, 화면 자막 |
| [beginner_project](beginner_project/README.md) | 선택 열도 써 보고 싶은 사용자 | 화면 맞춤·메모, 별도 자막 CSV |
| [multi_format](multi_format/README.md) | 세로·가로를 함께 만들 사용자 | 방향별 화면 맞춤과 `--layout both` |
| [title_project](title_project/README.md) | 고급 사용자·개발 검사 | 정확한 시간과 컷 경계를 넘는 Title |
| [simple_project](simple_project/timeline.csv) | 개발·호환성 검사 | 이전 3열 정밀 형식, 초보자는 건너뛰기 |
| [demo_project](demo_project/timeline.csv) | 개발·통합 검사 | 고급 설정, BGM, Caption |
| [system_neo](system_neo/README.md) | 기존 System Neo 기획 재현 | 18개 장면과 사용자 지정 Title 스타일 |
| [preview_output](preview_output/README.md) | 실행 전 결과 구조를 보고 싶은 사용자 | FCPXML·SRT 텍스트 미리보기 |

사진·영상 원본은 저작권과 용량 때문에 저장소에 넣지 않습니다. CSV의 `파일` 값을 자신이 가진 실제 파일명으로 바꾼 뒤, 그 파일들을 Colab에 함께 업로드하거나 프로젝트의 `Media/` 폴더에 넣으세요.
