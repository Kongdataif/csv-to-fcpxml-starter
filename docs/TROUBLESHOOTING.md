# 문제 해결

오류는 대부분 파일명, 사진·영상에 맞지 않는 열, 원본 시간 또는 결과 폴더 위치에서 생깁니다. 오류문에 표시된 **기획표 행 번호**, **현재 값**, **수정 안내**부터 확인하세요.

처음 작성하는 방법은 [사용자 가이드](USER_GUIDE.md), 기본 실행 순서는 [Mac·VS Code 가이드](MAC.md)를 참고하세요. 설치 없이 시험할 때만 [Colab 안내](02_BEGINNER_COLAB.md)를 사용합니다.

## 가장 먼저 확인할 다섯 가지

1. Colab에 `.xlsx` 또는 UTF-8 `.csv` 기획표를 올렸나요?
2. 기획표의 `파일`과 업로드 파일명이 대소문자·확장자까지 같나요?
3. 영상은 원본 시작·끝을 둘 다 채우거나 둘 다 비웠나요?
4. 사진에는 사진 표시 시간만, 영상에는 영상 원본 시간만 썼나요?
5. Mac에서 `Generated/`를 원래 `Media/` 옆에 놓았나요?

## Colab 업로드와 기획표

| 증상/메시지 | 원인 | 해결 |
|---|---|---|
| `.numbers` 파일은 직접 읽을 수 없습니다 | Numbers 원본을 그대로 업로드 | Numbers에서 `파일 > 다음으로 내보내기 > Excel`을 선택해 `.xlsx`로 저장한 뒤 새 파일 업로드 |
| `.xls` 또는 `.xlsm`을 사용할 수 없습니다 | 예전 Excel 형식 또는 매크로 파일 | Excel·Numbers에서 매크로 없는 `.xlsx`로 저장해 다시 업로드 |
| CSV 헤더가 없습니다 | 빈 파일 또는 첫 줄이 데이터 | 기본 템플릿의 6개 헤더를 첫 줄에 복사 |
| Excel 또는 Colab 표에서 CSV 한글이 `???` 등으로 깨짐 | CSV를 다른 문자 인코딩으로 열거나 깨진 상태로 저장 | 깨진 파일을 다시 저장하지 말고 [`.xlsx` 양식](../templates/simple_timeline.xlsx)을 다시 받거나 `CSV UTF-8`로 다시 내보낸 뒤 재업로드 |
| CSV를 UTF-8로 저장 | CP949/EUC-KR 등 다른 인코딩 | Excel·Numbers에서 CSV UTF-8로 다시 내보내기 |
| 필수 열 `파일`이 없습니다 | 헤더 오타·번역 | 초보자 템플릿의 `파일` 헤더를 그대로 사용 |
| 알 수 없는 열 | 헤더 오타 또는 임의 열 추가 | 기본 6열과 선택 열 `순서`·`화면 맞춤`·`세로 화면 맞춤`·`가로 화면 맞춤`·`메모`만 사용 |
| 헤더보다 값이 많습니다 | 셀 문장 안 쉼표가 CSV 구분자로 해석 | Sheets/Excel로 저장하거나 해당 셀을 큰따옴표로 감싸기 |
| `순서`에는 1 이상의 정수 | 빈칸, 0, 음수, 소수 또는 글자 | `1`, `2`, `3`처럼 입력 |
| 순서가 중복 | 두 행에 같은 숫자 | 각 장면에 중복 없는 순서 지정 |
| 미디어 파일을 찾지 못함 | CSV 이름과 업로드 이름 불일치 | 실제 파일명을 복사해 `파일` 셀에 붙여 넣기 |
| 업로드했지만 CSV에 연결되지 않음 | CSV에 없는 추가 파일 | 사용할 파일이면 행 추가, 아니면 업로드에서 제외 |
| 사진 또는 영상이 아닙니다 | 오디오 단독 파일·지원하지 않는 확장자 | 장면에는 사진/영상을 사용하고 BGM은 고급 설정 사용 |
| 영상 스트림을 찾지 못함 | 확장자만 영상이거나 손상된 파일 | 원본을 확인하고 호환 MOV/MP4로 다시 내보내기 |

## 파일명의 대소문자·확장자·Unicode

Colab은 Linux 환경이므로 다음은 서로 다른 파일입니다.

~~~text
office.MOV
office.mov
Office.mov
~~~

기획표에는 실제 이름을 정확히 적습니다. 확장자를 숨기는 Windows 탐색기 또는 Finder를 사용한다면 파일 정보에서 전체 이름을 확인합니다.

### 한글 파일명이 눈으로는 같은데 중복이라고 나옵니다

Mac의 일부 파일명은 한글 자모를 분해한 Unicode NFD, 다른 환경은 조합된 NFC로 저장할 수 있습니다. 화면에는 같아 보여도 내부 문자열이 다릅니다. 공개 Colab은 CSV와 실제 업로드 이름의 정확한 일치를 요구하며 대소문자·정규화 후 같은 업로드가 여러 개면 충돌로 거부합니다. Mac 로컬 어댑터만 정확한 이름이 없고 NFC/NFD 표현이 같은 후보가 하나일 때 자동 연결하고 경고합니다.

해결:

1. 충돌 파일 중 하나의 이름을 `scene_01.mov`, `scene_02.mov`처럼 명확히 바꿉니다.
2. CSV의 `파일`도 새 이름으로 수정합니다.
3. Colab 런타임을 다시 시작하고 CSV와 미디어를 다시 올립니다.

폴더 두 곳에 같은 `intro.mov`가 있더라도 직접 업로드에서는 한 폴더로 취급됩니다. 중복되지 않는 이름으로 바꾸세요.

## 영상 원본 시작·끝

### 시작만 또는 끝만 입력했다고 나옵니다

~~~csv
영상 원본 시작,영상 원본 끝
00:00:12.000,
~~~

도구는 끝을 영상 끝으로 추측하지 않습니다. 다음 중 하나로 고칩니다.

- 일부 구간: 시작과 끝을 모두 입력
- 영상 전체: 시작과 끝을 모두 비움

~~~csv
영상 원본 시작,영상 원본 끝
00:00:12.000,00:00:16.000
~~~

### 원본 끝이 영상 길이를 넘습니다

`00:00:16.000`처럼 보이는 영상도 실제 스트림 길이가 15.967초일 수 있습니다. 검사 결과에 표시된 원본 길이보다 끝을 짧게 줄이거나 전체 사용을 선택합니다.

### 원본 끝이 시작보다 앞입니다

시작과 끝을 바꾸었거나 시간 단위를 혼동했습니다. `00:01:02.000`은 1분 2초이고 `00:00:01.020`은 1.02초입니다.

### 영상에 사진 표시 시간을 쓸 수 없습니다

`사진 표시 시간(초)`은 정지 사진 전용입니다. 영상의 사용할 길이는 다음 중 하나로 정합니다.

- 전체 사용: 원본 시작·끝 모두 빈칸
- 일부 사용: 원본 시작·끝 모두 입력

영상 길이를 3초로 강제로 늘이거나 줄이는 자동 속도 변경은 제공하지 않습니다.

## 사진 표시 시간

### 사진이 생각보다 너무 길거나 짧습니다

- 셀이 빈칸이면 기본 3초입니다.
- `3`은 3초, `0.3`은 0.3초, `3000`은 3,000초입니다.
- `00:00:03.000`이 아니라 초 숫자 `3`을 쓰는 것을 권장합니다.
- Colab 설정의 `DEFAULT_PHOTO_DURATION`을 바꾸었다면 모든 빈 사진 행에 적용됩니다.

원하는 시간이 2.5초라면:

~~~csv
사진 표시 시간(초)
2.5
~~~

### 사진에 영상 원본 시작/끝을 입력할 수 없습니다

사진에는 원본 재생 시간이 없습니다. 두 칸을 비우고 `사진 표시 시간(초)`만 적습니다.

### 사진 변환에 실패합니다

사진을 PNG 또는 JPG로 다시 저장해 시도합니다. 손상 파일, 매우 특이한 색공간·코덱, 지원하지 않는 HEIC 변형은 FFmpeg가 읽지 못할 수 있습니다. 사진 캐시는 짝수 해상도의 호환 H.264 MP4로 생성됩니다.

## 소리와 화면 맞춤

| 증상 | 원인 | 해결 |
|---|---|---|
| 영상에 소리가 없습니다 | `소리=끄기` 또는 원본 영상에 오디오 스트림 없음 | `사용`/빈칸으로 바꾸고 원본 재생 확인 |
| 사진의 소리 값을 무시했다는 경고 | 사진 행에 `사용`/`끄기` 입력 | 사진은 소리가 없으므로 셀을 비움 |
| `0 dB`인데 무음이 아님 | 0 dB는 원본 레벨 유지 | 초보자는 `소리=끄기`, 고급은 include_audio=false 사용 |
| 화면 양옆/위아래에 여백 | `전체 보이기`가 원본 전체를 유지 | 꽉 채우려면 `화면 채우기`, 크롭 확인 필요 |
| 인물이나 글자가 잘림 | `화면 채우기`가 프레임을 채우며 가장자리 크롭 | `전체 보이기`로 변경하거나 Final Cut에서 위치 조정 |
| 화면 맞춤 값 오류 | 허용하지 않은 문구 | `전체 보이기`, `화면 채우기`, `자동 맞춤 안 함` 중 하나 사용 |

## 인라인 자막과 subtitles.csv

| 증상 | 원인 | 해결 |
|---|---|---|
| 인라인 자막과 별도 자막을 함께 쓸 수 없음 | `화면 자막` 값과 `subtitles.csv`가 동시에 있음 | 화면 자막 열을 모두 비우거나 별도 업로드 설정 끄기 |
| 한 장면에서 자막이 너무 오래 보임 | 인라인 자막은 장면 전체 길이 | 별도 subtitles.csv에서 정밀 시작·끝 지정 |
| 자막 시간이 겹침 | 같은 role/lane의 두 자막이 겹침 | 앞 자막 end와 다음 start를 겹치지 않게 수정 |
| Caption XML에 일부 자막 없음 | Caption이 컷 경계를 넘거나 gap에 위치 | 구간을 나누거나 Title/SRT 사용 |
| SRT가 없음 | `EXPORT_SRT=False` 또는 `--no-srt` | 설정을 True로 바꾸거나 옵션 제거 |
| Title이 보이지 않음 | `화면 자막`이 비었거나 clean XML을 가져왔거나 Title 비활성 | 자막이 있을 때 생성된 `*_with_titles.fcpxml`을 가져오고 Title 활성 확인 |
| 기본 Share에 자막이 없음 | Caption을 Title로 오해 | 일반 영상은 Basic Title 결과 사용. Caption은 Share 설정 필요 |

초보자 `화면 자막`은 생성된 장면 전체 길이로 Basic Title과 SRT에 들어갑니다. 정밀 자막의 `시작`, `끝`은 원본 영상 시간이 아니라 완성 타임라인 시간입니다.

## Colab 업로드가 느리거나 멈춥니다

Colab의 브라우저 업로드는 대용량 영상 전송 서비스가 아닙니다. Google은 모든 계정에 고정된 업로드·디스크·런타임 한도를 보장하지 않습니다.

- 브라우저 탭을 열어 두고 컴퓨터 절전을 잠시 끕니다.
- 안정적인 네트워크를 사용합니다.
- 불필요한 원본은 업로드에서 제외합니다.
- 먼저 짧은 저해상도 복사본으로 CSV 흐름을 검증합니다.
- 수 GB 4K·ProRes 또는 반복 변환은 [Mac 로컬 실행](MAC.md)을 사용합니다.
- 런타임이 초기화되었다면 파일은 복구되지 않으므로 처음부터 다시 올립니다.

GPU를 켜도 CSV, FFprobe와 XML 생성은 크게 빨라지지 않습니다.

### 공개 소스 SHA-256 불일치로 중단됩니다

고정 릴리스가 가리키는 핵심 코드와 노트북에 기록된 검토 해시가 다릅니다. 미디어를 업로드하기 전에 멈추는 것이 정상입니다.

- URL의 공식 릴리스 노트북인지 확인합니다.
- 임의로 `SOURCE_HASHES_READY`를 바꾸거나 오류를 우회하지 않습니다.
- 저장소 게시자가 새 릴리스와 해시를 함께 갱신했는지 확인합니다.
- 저장소 배포자라면 [배포자 가이드](PUBLISHING.md)와 [개발 가이드의 소스 무결성 갱신](DEVELOPMENT.md#소스-무결성-값-갱신)을 따릅니다.

## 기밀·민감한 미디어를 올려도 되나요?

Colab은 내 Mac에서 내려받은 코드를 실행하지 않는 대신 파일을 Google의 임시 VM으로 업로드합니다. 다음은 Colab에 올리지 않는 것을 권장합니다.

- 회사 기밀·NDA·환자·고객 자료
- 공개 전 광고·제품·방송 원본
- 민감한 얼굴, 음성, 집 주소, 위치 메타데이터
- 업로드·편집 권한이 없는 타인의 자료

이런 자료는 검토한 소스를 [Mac 로컬 환경](MAC.md)에서 실행하여 원본이 기기를 떠나지 않게 합니다. Colab 사용 후에는 결과를 받고 `런타임 > 연결 해제 및 런타임 삭제`를 선택합니다. 공개 이슈에 원본이나 자막 전문을 올리지 않습니다.

## 결과 다운로드와 manifest

### 다운로드 ZIP 생성이 거부되었습니다

결과 허용 목록 밖의 파일이 발견된 것입니다. 공개 Colab 결과에는 다음만 허용됩니다.

- `.fcpxml`, `.srt`, `.txt`, `.json`
- 사진 캐시 `Generated/vertical_9x16/.build_media/*.mp4` 또는 `Generated/horizontal_16x9/.build_media/*.mp4`
- 루트 `manifest.json`

`.py`, `.sh`, `.command`, `.app`, `.pkg`, `.exe`, 심볼릭 링크가 들어가면 패키징을 중단합니다. 임의로 허용 목록을 넓히기보다 `build_report.txt`와 노트북 오류를 확인해 이슈를 보고합니다.

### manifest 해시가 맞지 않습니다

다운로드가 불완전하거나 압축 해제 후 파일이 바뀌었을 수 있습니다. Colab 결과를 새로 생성하고 다시 다운로드합니다. `manifest.json`의 `sha256`은 해당 결과 파일 내용의 SHA-256입니다.

## Final Cut에서 미디어가 오프라인입니다

가장 흔한 원인은 XML과 원본의 상대 위치가 달라진 것입니다.

정상 구조:

~~~text
MyVideo/
├─ Media/
│  ├─ cafe_boot.mov
│  └─ photo.png
└─ Generated/
   ├─ vertical_9x16/
   │  ├─ MyVideo_vertical_9x16_clean.fcpxml
   │  ├─ MyVideo_vertical_9x16_with_titles.fcpxml
   │  └─ .build_media/
   └─ horizontal_16x9/
      ├─ MyVideo_horizontal_16x9_clean.fcpxml
      ├─ MyVideo_horizontal_16x9_with_titles.fcpxml
      └─ .build_media/
~~~

확인 순서:

1. 다운로드 ZIP의 `Generated/`를 원래 `Media/`와 같은 프로젝트 폴더에 놓습니다.
2. `Media`의 대문자 M과 파일명을 CSV 작성 후 바꾸지 않았는지 봅니다.
3. 사진을 썼다면 `.build_media/`가 가져올 XML과 같은 방향 폴더 안에 있는지 확인합니다.
4. XML만 Desktop/Downloads로 따로 옮기지 않습니다.
5. 구조를 복원한 뒤 Final Cut에서 Relink Files를 사용합니다.

Windows나 Linux에서 만든 결과도 `MyVideo/` 전체를 Mac으로 옮기면 됩니다. XML에 `/content/...`가 보이면 상대경로 생성 검사가 우회된 비정상 결과이므로 새 노트북으로 다시 만듭니다.

## Final Cut import와 Title

| 증상 | 원인 | 해결 |
|---|---|---|
| XML import 오류 | FCPXML 버전, 구조 또는 의미 오류 | Final Cut Pro 11.2 이상 또는 FCPXML 1.14 지원 버전인지 확인하고 clean XML부터 import |
| Final Cut Pro 11.1 이하에서 오류 | FCPXML 1.14 미지원 | Final Cut Pro 11.2 이상 또는 이후 호환 버전 사용 |
| clean은 되고 Title만 실패 | Basic Title resource/스타일 문제 | 전체 오류와 버전 기록, 최소 자막으로 재현 |
| Title 폰트가 다름 | 대상 Mac에 폰트 미설치 | 정확한 폰트 설치 후 Final Cut 재실행 |
| Title 위치·윤곽선이 다름 | FCP 렌더링·해상도·스타일 차이 | 실제 Mac에서 project.json 설정 조정 |
| MOV/MP4를 Final Cut이 거부 | 컨테이너 내부 코덱 비호환 | 대상 Mac 재생 확인 후 ProRes 또는 호환 H.264/AAC로 변환 |

Basic Title import 문제 확인 순서:

1. Final Cut Pro 11.2 이상 또는 FCPXML 1.14 지원 버전인지 확인합니다.
2. 같은 폴더의 `*_clean.fcpxml`을 가져옵니다.
3. clean은 되고 `*_with_titles.fcpxml`만 실패하면 자막 한 행의 최소 예제로 줄입니다.
4. 로컬에서는 `python scripts/validate_fcpxml.py --check-media 결과.fcpxml`을 실행합니다.
5. macOS·Final Cut 정확한 버전, 전체 오류문과 `build_report.txt`를 기록합니다.

XML well-formedness나 Apple DTD에 가까운 구조 검사도 실제 Final Cut import·Motion Title 로딩과 렌더링을 완전히 대신하지는 않습니다.

## Mac 로컬·고급 모드 오류

| 증상/메시지 | 원인 | 해결 |
|---|---|---|
| `python3: command not found` | Python 미설치 | Python 3.10+ 설치 후 Terminal 재실행 |
| ffprobe/ffmpeg를 찾지 못함 | 운영체제 명령 미설치 | `brew install ffmpeg` |
| Media 폴더가 없습니다 | 프로젝트 구조 오류 | timeline.xlsx 또는 timeline.csv 옆에 대문자 M의 `Media/` 생성 |
| source와 timeline 길이가 다름 | 정밀 모드에서 자동 retime 범위 밖 | source 구간과 타임라인 길이를 같게 수정 |
| 주 스토리라인 클립이 겹침 | 정밀 `timeline_in/out` 겹침 | 위치 수정, gap은 허용 |
| 출력 폴더가 프로젝트 밖이라 거부 | 안전한 기본 경로 제한 | output_dir를 내부로 바꾸거나 검토 후 `--allow-external-output` |
| subtitles와 captions 동시 활성 | 새 설정과 v0.2 호환 설정 충돌 | 새 프로젝트는 subtitles만 사용 |
| BGM·자막 파일 없음 | 설정만 활성화되고 파일 누락 | 파일을 넣거나 해당 설정을 끔 |
| 기존 cache 길이가 잘못됨 | 구버전 캐시 | Generated를 백업하고 v0.6.0으로 다시 생성 |

Mac 간편 CLI와 Colab 모두 `.xlsx`와 UTF-8 `.csv`를 받습니다. Numbers 기획표만 `파일 > 다음으로 내보내기 > Excel`로 `.xlsx`를 만든 뒤 사용하세요. 같은 폴더에 `timeline.xlsx`와 `timeline.csv`가 모두 있으면 하나를 지우거나 `--timeline`으로 명시합니다.
