## 2-1. 기획표부터 작성하자

기획표 한 행은 장면 하나다.
어떤 파일을 사용할지, 원본의 어느 부분을 가져올지, 무슨 문장을 띄울지 적는다.

GitHub의 `templates` 폴더에서 `timeline.csv` 또는 `timeline.xlsx`를 열고 원본 다운로드 버튼으로 받는다.
Excel 양식은 `timeline` 시트에 작성한다. 첫 행의 열 이름은 유지한다.

| 열 | 입력할 내용 |
|---|---|
| 파일 | 원본 파일명과 확장자. intro.mov처럼 적는다. |
| 영상 원본 시작 | 영상에서 사용할 구간의 시작 |
| 영상 원본 끝 | 영상에서 사용할 구간의 끝 |
| 사진 표시 시간(초) | 사진을 보여줄 시간. 빈칸은 3초 |
| 화면 자막 | 해당 장면에 표시할 문장. 빈칸은 자막 없음 |
| 소리 | 사용 또는 끄기. 빈칸은 원본 소리 사용 |

영상의 시작·끝을 모두 비우면 전체 영상을 쓴다. 사진은 영상 시작·끝을 비운다.
양식의 파일명은 설명용이다. 내 실제 원본 이름으로 바꿔야 한다.

```csv
파일,영상 원본 시작,영상 원본 끝,사진 표시 시간(초),화면 자막,소리
intro.mov,00:00:01.000,00:00:05.000,,첫 장면,사용
photo.jpg,,,3,사진 장면,
outro.mp4,00:00:02.000,00:00:07.000,,마지막 장면,끄기
```

첫 행의 1초~5초는 완성 영상의 1초 지점에 놓으라는 뜻이 아니다.
**원본 영상에서 그 구간을 가져오라는 뜻**이다.

```text
0~4초    intro.mov의 원본 1~5초
4~7초    photo.jpg를 3초 표시
7~12초   outro.mp4의 원본 2~7초
```

장면의 타임라인 위치는 코드가 계산한다. 나는 사용할 구간과 순서를 정하면 된다.
XLSX로 저장하거나 UTF-8 CSV로 저장한다. 둘 중 하나만 준비한다.
Numbers는 파일 > 다음으로 내보내기 > Excel로 저장한다.

## 3. GitHub에서 Colab 열기

저장소 첫 화면의 **Open in Colab**을 누른다.
노트북 이름은 `colab.ipynb`다. 빈 노트북을 만들거나 코드를 복사할 필요는 없다.

[촬영 자리: 저장소의 Colab 버튼]

### 1번: 실행 코드 준비

셀 왼쪽 실행 버튼을 누른다. 준비가 끝나면 코드 커밋과 작업 폴더 경로가 표시된다.
GPU를 선택할 필요는 없다. 원본은 Google 실행 환경에 올라가므로 민감한 파일은 Mac 로컬에서 처리한다.

### 2번: 기획표 업로드

CSV 또는 XLSX 한 개를 선택한다.
**기획표 저장 완료**와 장면 목록이 출력되는지 확인한다.
이 창에는 사진과 영상을 함께 올리지 않는다.

### 3번: 사진·영상 업로드

기획표에 적은 원본을 모두 선택한다.
**미디어 저장 완료**가 나오면 다음으로 이동한다.
누락된 파일이 있으면 이름을 알려주고 중단한다. 그 파일을 포함해 전체를 다시 선택하자.

### 4번: 화면 방향을 정하고 변환

| 설정 | 선택 |
|---|---|
| LAYOUT | portrait: 세로 / landscape: 가로 / both: 둘 다 |
| FIT | fit: 원본 전체 표시 / fill: 화면을 채우고 가장자리 자름 |

프로젝트는 30fps다. 처음에는 portrait, fit으로 시험해보자.
실행 후 **변환·결과 검증 완료**가 나오면 다음으로 넘어간다.
오류가 났다면 표시된 입력 문제부터 고친다. 실패한 실행의 이전 결과는 다운로드할 수 없다.

[촬영 자리: 화면 방향 설정과 변환 완료]

### 5번: 결과 다운로드

마지막 셀을 실행하면 `fcpxml-result.zip`을 받는다.
**이 ZIP은 코드 설치 파일이 아니라, XML과 사용한 원본·사진 캐시를 묶은 결과물**이다.
다른 사람에게 공유하기 전에 들어 있는 원본을 확인하자.

기획표를 바꾸면 2번부터, 원본만 바꾸면 3번부터, 화면 설정만 바꾸면 4번부터 다시 진행한다.
1번 재실행은 새 작업이므로 모든 파일을 다시 올려야 한다.

## 4. Final Cut Pro에 가져오기

이제 Mac으로 돌아온다.
ZIP의 압축을 풀고 `Media`와 `output`을 같은 폴더 안에 그대로 둔다.

```text
fcpxml-result/
├─ timeline.csv 또는 timeline.xlsx
├─ Media/
└─ output/
   ├─ portrait.fcpxml 또는 landscape.fcpxml
   ├─ build_report.json
   └─ media/
```

both라면 XML이 두 개 생긴다. XLSX 입력이면 output/timeline_converted.csv도 생성된다.
사진을 썼다면 output/media에 MP4 캐시가 있다. XML만 꺼내 옮기지 않는다.

Final Cut Pro에서 **파일 > 가져오기 > XML**을 선택한다.
세로는 output/portrait.fcpxml, 가로는 output/landscape.fcpxml을 가져온다.

[촬영 자리: XML 가져오기와 생성된 타임라인]

기획표 예시라면 4초, 3초, 5초 장면이 총 12초로 이어지는지 확인한다.
원본 소리와 화면 잘림, 글자의 크기·위치도 살펴본다.

기획표에는 '화면 자막'이라고 적지만 여기서는 **Basic Title**로 만든다.
일반 캡션 트랙이나 별도 SRT를 추가하는 과정은 없다. 타이틀 클립에서 문구와 모양을 수정한다.

미디어가 보이지 않으면 **파일 > 파일 다시 연결 > 원본 미디어**에서 찾는다.
사진 장면은 원본 사진이 아니라 output/media의 MP4를 다시 연결해야 한다.

이제 빈 타임라인에서 시작하지 않아도 된다.
장면을 고르는 것은 내가, 정해진 순서와 시간대로 배치하는 반복 작업은 코드가 맡는다.

다만 Final Cut Pro에서 수정한 내용이 CSV에 자동으로 반영되는 것은 아니다.
기획표 재실행은 새 초안을 만드는 일이다. 결과마다 새 폴더에 압축을 풀어 기존 작업을 보존하자.

## 작성자 확인

이 원고는 Generated, .build_media, with_titles, clean, SRT, OK 입력 단계를 사용하지 않는다.
실제 화면으로 촬영한 뒤 게시한다. FCPXML 1.14의 가져오기는 Final Cut Pro 12.0 이상에서 확인한다.
